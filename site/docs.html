Implementer manuals

Docs

This product site is the short path. The manuals below are the deep path: every field, flag, error code, and connector option. They live in the repo as Markdown and open on GitHub.

Normative contracts (JSON Schema, Query IR, typed errors) stay in planning/. If a manual and planning/ disagree, planning wins. Product rule labels (D17–D22) are explained on Decisions Contribute — do not treat the bare id as enough context.

Start here if you are writing YAML from zero: from-scratch.md and field-reference.md. Index: docs/en/README.md.
